1. Return ONLY the C++ code - no explanations, no markdown fences

4. Follow Google C++ Style Guide

   - None -> nullptr or std::optional
   - bool -> bool
   - int -> int or int64_t
   - float -> double
7. Convert Python classes to C++ classes with proper constructors
8. Use references and const where appropriate
9. Handle file I/O with std::ifstream/std::ofstream

# Output
Return valid C++ code that compiles with g++ -std=c++17.
